# 2026-06-02 指标口径排查进展

## 阶段 1：定位问题范围

- 用户反馈线上页面 `russia-pl-calculator` 中红框指标对不上，截图涉及：运营净利、项目净利、期末账上现金、月度明细底部当月净利合计、累计现金。
- 本地项目已确认是 Vite + React 应用，核心逻辑在 `src/App.jsx`，文案在 `src/i18n.js`。
- 初步定位到源码中这些指标并非同一公式：
  - 经营净利：商品经营利润口径。
  - 项目净利：经营净利扣一次性启动费后的项目利润口径。
  - 期末账上现金：按月现金流累计后的账上余额，包含补货、固定支出、分润/提现等现金流影响。
  - 月度明细底部当月净利合计：月度利润表合计口径，可能与总览卡片的经营净利是否扣固定月费/是否按完整排期有关。
- 下一步：用线上页面和本地源码逐项核对具体公式，确认是否存在前端展示或汇总口径不一致的问题。

## 阶段 2：初步结论

- 继续核对源码后确认，页面里“术语说明 / 现金流说明”已经说明了这类差异：
  - `运营净利` 是经营利润口径，不含一次性启动费。
  - `项目净利` 是运营净利扣除一次性启动费后的口径。
  - `期末账上现金（已扣分润）` 是现金流口径，会叠加首批备货、补货节奏、固定支出、分润/提现后的账上余额。
  - 月度明细表里的 `当月净利` 是按月度排期汇总出来的损益口径，不等同于总览卡片里的经营净利卡片。
- 因此截图中的几个红框数值不一样，当前更像是“指标口径不同导致的正常差异”，不是已经确认的计算错误。
- 后续如需优化，建议不是改公式，而是在红框指标附近增加更短的提示文案，避免用户误以为这些值必须互相相等。

  - `项目利润：扣掉前期费用后还剩多少`
