# 独立客户版阿里云部署说明

## 当前形态

这个版本不再把 Supabase 作为正式后端。

正式结构是：

```text
前端 React/Vite
后端 FastAPI
数据库 阿里云 RDS PostgreSQL
服务器 阿里云 ECS + Nginx
```

客户打开 `/p/项目slug` 时，需要输入访问码。通过后只能完整只读查看，不能保存、发布、删除或进入项目库。
客户公开页不会显示后台编辑入口；如果报价、报关价、重量或包装规格变化，需要内部人员登录后台更新并重新发布。

## 本地启动

首次本地启动：

```powershell
pip install -r requirements.txt
npm install
```

复制环境变量：

```powershell
Copy-Item .env.example .env
```

启动：

```powershell
.\一键启动损益计算器.bat
```

默认后端：

```text
http://127.0.0.1:8018
```

默认前端：

```text
http://127.0.0.1:5173
```

默认后台账号来自 `.env`：

```text
ADMIN_USERNAME
ADMIN_PASSWORD
```

## 迁移旧公开项目

启动后端后运行：

```powershell
python scripts/migrate_legacy_projects_to_backend.py
```

脚本会把现有公开 JSON 导入数据库，并给公开项目设置默认访问码：

```text
DEFAULT_PUBLIC_ACCESS_CODE=xhk2026
```

## 阿里云部署建议

推荐使用：

```text
ECS：运行 FastAPI + Nginx
RDS PostgreSQL：保存项目数据
Nginx：托管 frontend-dist，并把 /api 转发到 FastAPI
```

生产 `.env` 至少配置：

```text
DATABASE_URL=postgresql://user:password@host:5432/dbname
JWT_SECRET=一串很长的随机字符串
ADMIN_USERNAME=admin
ADMIN_PASSWORD=强密码
CORS_ORIGINS=https://你的域名
PUBLIC_BASE_URL=https://你的域名
DEFAULT_PUBLIC_ACCESS_CODE=xhk2026
ENV=production
```

## Nginx 关键配置

示例：

```nginx
server {
  listen 80;
  server_name your-domain.com;

  root /opt/russia-pl-calculator/frontend-dist;
  index index.html;

  location /api/ {
    proxy_pass http://127.0.0.1:8018/api/;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
  }

  location / {
    try_files $uri $uri/ /index.html;
  }
}
```

## 上线验收

- 后台 `/login` 可登录。
- `/app/projects` 能看到项目库。
- 新建项目后保存，刷新仍存在。
- 发布项目后 `/p/:slug` 要求输入访问码。
- 输入正确访问码后能完整只读查看。
- 错误访问码不能进入。
- 项目库里可以对公开项目点击“重置访问码”。
- 手机端公开页不出现页面级横向溢出。
